# 报价工作台

Python 本地软件：上方粘贴多笔债券报价，下方生成可编辑的蓝白工作表。可设置本方公司，判断买入、卖出与非本方交易，逐行核对原文和字段依据。

**仓库中的债券、机构、联系人、联系标识、价格及交易代码均为人工编写的虚构测试数据。真实报价、本地设置、保存记录和导出文件不随仓库发布。**

## 启动

需要 Python 3.10 或以上，无第三方依赖。Windows 双击 `启动软件.cmd`，保持启动窗口开启，默认浏览器会打开工作台。也可以运行：

```powershell
python app.py
python app.py --no-browser --port 8765
```

默认地址为 http://127.0.0.1:8765，端口被占用时选择空闲端口，以启动窗口显示的地址为准。关闭窗口或按 Ctrl+C 停止。此版本是 Python 本地应用，不包含独立 EXE 或 Python 安装包。

## 使用

1. 填写本方公司和别名，打开“识别口径”设置金额、方向、K 单位及无标签利率口径。点击“保存为本机默认”才会保存配置。
2. 在上方粘贴报价，约半秒后自动识别，也可点击“识别报价”或按 Ctrl+Enter。“载入虚构样例”可试用六笔完整流程。
3. 在表格直接修改代码、简称、业务类型、金额、价格、收益率、机构、备注和工作状态。业务类型分为普通报价、回推要素、组合/架桥，独立于买卖动作；无标签利率显示为候选，可单独确认。筛选、搜索及“只看待复核”用于定位问题。
4. 表格可横向滚动。“展开全部要素”显示买卖双方、日期、清算速度、期限、联系人、约定号、理论价格及附注金额；券名下的“查看原文／复核 N 项”显示原文行号、依据、复核项和修改记录。
5. 点击“保存本地”创建新版本，从批次下拉框恢复。已保存未提交为黄色，已提交为蓝色；蓝色只是手工工作标记，软件不连接交易系统。
6. 导出 CSV 可用 Excel 打开；JSON 保留原文、首次识别快照、当前字段、设置、依据和修改记录。导出当前全部结果，不受筛选影响。

已修改表格时，变更原文或识别口径会提示重新识别，避免自动覆盖修改；重新识别后可撤销到上一批结果。手工修改买方、卖方、动作和对手方是独立修正，需要一并核对，不会静默推算其他字段。

## 信息如何提取

核心是**分笔规则、字段标签、模板上下文、机构别名和校验**。不调用云端大模型，也不是训练出的通用语义模型。

```text
原始文本 → 全半角标准化 → 分组/报告归属识别 → 代码或简称分笔
        → 标签提取 + 模板字段定位 → 金额换算/别名归一/本方方向
        → 缺失与冲突复核 → 可编辑表格 → 显式本地保存/导出
```

- **先分笔**：优先用 .SH、.SZ、.IB 债券代码识别新记录，也识别以年份和中文简称开头的缺代码报价。日期和机构方向写在代码上一行时归入下一笔，不串到上一笔；联系人与交易代码附在所属报价。买入、卖出、回推要素和组合标题作为上下文，报告抬头决定分组动作所属公司。
- **优先读标签**：“净价”“全价”“行权”等标签比数字位置可靠。先隔离括号内理论价格、返还/费用附注，再提取实际价格，避免把备注数字当成报价或面额。
- **再用模板**：面额后的价格和候选利率允许换序；买入要素也可出现“期限、代码、简称、候选利率、面额”。标签优先，无标签数字仅在可消歧时分配：当前启发范围为价格20至200、利率绝对值小于20，只有唯一搭配才使用。这是模板启发，不是字段有效值限制，显式标签可超出这些范围；无法消歧时保留原值并复核。无标签利率按设置作为候选或已确认值；缺省收益率留空。
- **金额单位**：W/w 与万元按万元处理，无单位金额按设置处理；K 默认不换算，只有明确选择 `1K = 1000 万元` 才转换。使用 Decimal 计算，JSON 数值用十进制字符串保存，不把面额当成交金额。
- **拆分面额**：支持以加号连接的面额，按已确认单位计算合计，并在备注保留拆分写法。JSON 中 amount_expression 保留表达式，amount_components 保留每段面额及单位；不执行文本表达式，也不自动拆成多笔成交。单位无法统一确认时保留明细并提示复核。
- **方向与机构**：按 to、箭头或独立的“出”识别两端，默认左卖右买，再与本方及别名匹配。没有双端方向时可用分组归属推断；分组与明确方向冲突则待确认。产品名称保留，不合并机构旗下不同产品。
- **业务类型**：组合或架桥分组中的报价标记为“组合/架桥”，回推分组标记为“回推要素”，其他报价默认“普通报价”，均可手工修改。组合买卖两端分别保留，不合并同券记录、不自动声称已成交或已赚取利差；原分组标题和行号可追溯。
- **日期与期限**：识别八位 YYYYMMDD、带分隔符的完整日期、月日、+0 清算速度、Y + N 期限等。日期先按日历校验并从数字分配中排除，无效首部日期提示复核，不作为面额或收益率。无年份时只保留月日，不推断年份；日期用途不清则提示，不计算交易日历。
- **联系人**：识别姓名、数字联系标识、QT号、同一行括号联系人、约定号和机构后的 Z 代码。没有明确机构不按顺序绑定；粘连或未识别文字保留在备注及原文。
- **粘连与多个约定号**：机构和姓名无空格时，可依据本机已知别名或常见机构后缀暂拆为候选，并提示核对机构/产品全称。完整保留多个约定号（含前导零），不把后续约定号误分配成价格或收益率；不按出现次序把约定号绑定到拆分面额。
- **可追溯**：保留原文、行号、字段片段与规则依据，修改记录保留前后值。完整重复报价标记但不删除，同券不同价格仍各占一行。

例如虚构文字 `900010.SH 27演示债丁 360 净价97.6543（理论价格97.7000，还我1234）示例甲证券 to 示例乙银行`：面额360万元、实际净价97.6543、独立理论价格97.7000；返还附注单独保留并复核。本方为示例甲证券时是卖出，改为示例乙银行重新识别则为买入。

## 本地数据与配置

- 服务仅监听127.0.0.1，页面资源、解析、校验和 SQLite 保存均在本机，不加载外部脚本、字体或模型。
- 粘贴和识别本身不创建业务数据库。点击“保存本地”后写入 `.local-private/software/quotes.sqlite3`，每次保存创建新批次，保留旧版本。
- 默认配置保存在 `config.local.json`。源码中的 `config.json` 只含虚构机构字典。真实别名、临时配置、原文及输出目录已加入 Git 忽略。
- 数据库是普通本地文件，不提供文件加密、用户登录或跨机器同步。JSON/CSV 可能含原文或联系信息，应按所在单位要求保存。
- 静态 HTTP 仅提供三份界面文件；私有配置与数据库不能通过静态路径下载。写入接口检查本机 Host、来源及专用请求头。这不是共享网络服务。

Python 调用：

```python
from structured_parser import parse_quotes
result = parse_quotes(
    '900010.SH 27演示债丁 360 净价97.6543 示例甲证券 to 示例乙银行',
    {'self_company': '示例甲证券', 'default_amount_unit': '万元'},
)
for row in result['records']:
    print(row['action'], row['amount_wan'], row['quote_price'], row['issues'])
```

`quote_parser.py` 保留早期命令行接口，配置与新工作台分开：

```powershell
python quote_parser.py examples/demo.txt --out outputs/demo
```

早期接口默认只保存 to 两端、不自动映射方向；新工作台默认左卖右买。不要混用两种配置字段。


当前66项测试覆盖旧接口、新分笔与模板、方向反转、费用隔离、K 单位、人工修正及本地保存恢复，包含八位日期、有／无收益率、价格收益率换序、跨行表头、组合类型、拆分面额、粘连姓名及多个约定号的回归用例。浏览器验证覆盖桌面与窄屏、价格修改、收益率确认、状态保存和原文核对。测试全部使用虚构数据，未给出实测准确率。

格式不固定时仍需扩展规则和人工复核。未连接证券主数据，不能验证代码与简称对应关系；缺代码不会联网补齐。同一行塞入多笔、特殊跨行模板或未知机构粘连可能无法正确拆分，需分行后识别。单次最多30万字符，保存单批最多500笔。
